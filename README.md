# dsh-moyu

**DSH 摸鱼插件｜每日签到与缓慢养成，给 agent 干活时的你一点消遣。**

基于 [DeepSeek Harness (dsh)](https://github.com/deepseek-ai/dsh)

</div>

## 这是什么

一个住在 DSH 里的签到养成系统。它的初衷只是摸鱼——当初随便一想，没想到真的一点点做出来了。

**它该放在创意那一栏，而不是任何正经分类。** 闲得没事种个菜、占个矿洞，谁会正事不干专门来搞它？它本来就是个摸鱼工具：

> 随便点两下，然后一直等，时间到了再点两下。
>
> 想摸鱼的时候，它就很好玩，你会真的投入进去；不想玩的时候，点一下立刻退出来干你的事，过十几个小时再来签个到——每天都能签，没人限制你。
>
> 玩法也能自己调：想要高爆率就调高爆率，想要长得快就调快。**这何尝不是一种摸鱼。**

## 安装

### 一行指令（推荐）

把下面这一行**原样复制**，发给 DSH：

```
安装插件：https://github.com/yizhiyangyangqwq/dsh-moyu
```

DSH 会自己完成下载、安装和挂载。装完**重启 DSH**，左下角用户名上方会出现一个带可领数量的签到徽章。

> 私有仓库的话，用 `安装插件：github:yizhiyangyangqwq/dsh-moyu` 这种写法，或者先 `git clone` 到本地再用下面的方式。

### 本地目录

如果你已经把仓库克隆到本地：

```
安装插件：E:/path/to/dsh-moyu
```

（用正斜杠或反斜杠都可以，指向 `package.json` 所在的那个目录。）

### 装好之后

- 重启 DSH，插件才会完全生效
- 第一次打开会看到「公告」页，里面是这个版本的更新说明
- 「关于」页有作者的话和 B 站主页链接

> 插件不会自己联网。只有你在「公告」里点「检查更新」或「更新」时，它才会发出一次网络请求——这一点在设置里可以查，默认关闭。

## 三个入口

插件在界面上有三个位置，**其中两个必须至少留一个**：

| 入口 | 在哪 | 能否关掉 |
|---|---|---|
| 签到徽章 | 左下角用户名上方，带可领数量 | 可关，但不能和下面那行同时关 |
| 侧边栏入口 | 面板列表里的「签到」 | 可关，但不能和上面那个同时关 |
| **设置页签到行** | DSH 设置 → 通用里的一行 | **随时可关，不受配对限制** |

前两个是**门**——设置页就藏在门后面，两扇都关上就没有任何地方能再把它们打开了。所以"至少留一个"是硬约束。

第三个是**捷径，不是门**：它给你一条不用打开插件就能签到的路（一键领完所有就绪项），关掉它不影响另外两个。所以它什么时候都能关。

## 上手之后

### 签到是主线，但从不逼你

8 种周期长短差得很开，是刻意的：**无论你什么时候打开，总有一项可以领。**

连签断掉只是归 1，不罚钱、不删档。离开一周回来，作物还在成熟，机器还在运转，离线收益攒着等你。

### 难度自己定

设置里有 22 个可调项。奖励倍率调到 10×、病害调到 0、生长速度调到 8×——**这是你自己给自己定的难度，不是平衡性设定**，README 和面板里都这么写。

### 两条开店路线

第一次打开开店会先问你：想走**自动化**还是**工作化**？

|  | 自动化 | 工作化 |
|---|---|---|
| 干活的是谁 | 机器 | 你自己 |
| 你离开时 | 照常运转 | 不赚 |
| 单次收益 | 略低 | **更高**（×1.35） |
| 上限 | 每小时固定 | 只看你点多久 |
| 适合谁 | **没时间的人** | 有时间、想真的玩的人 |

选错了能改——之后花钻石就能换，第一次选永远免费。换路线**不退机器也不没收**，已经买的机器继续运转。

### 钓鱼要眼快手准

下竿后漂着，某个随机时刻咬钩，然后开一个很短的窗口。**抢早了它会跑，慢了它也会跑。**

失败只花时间，不扣钱。窗口随鱼竿变宽，越好的鱼竿越宽容。

## 公告与更新

「公告」页存放版本更新记录：

- **可收起展开**——默认只展开最新一条，其余收成标题行；顶上有「全部展开 / 全部收起」
- **一键已读**——读完后标签圆点消失，状态存在 `settings.json` 里，`/reset` 和转生都不会清掉
- **自动重新变未读**——已读标记记的是版本号而不是布尔值，所以发布新版本时圆点会自动亮起

更新时插件会先下载校验，再备份，最后原子替换。**任何一步失败都会把所有文件一起还原**，不会留下半新半旧的版本。

## 隐私

- 所有进度存在你自己机器的本地文件里，**不上传**
- 插件**不会自己联网**——只有你在「公告」里点检查和更新时才会
- 关于页有作者头像和一句话：「所有进度都存在你自己机器的本地文件里，不上传。插件不会自己联网。」

**1117 项断言，13 个套件，全部通过。**

发布新版本：

```powershell
# 1. package.json 和 index.js 里同时改版本号（两边必须一致）
# 2. index.js 的 CHANGELOG 里加一条
& $node tools\build-dist.mjs
# 3. 提交 dist/ 并推送
```

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.js` | 宿主。存档、时钟、经济、成就判定、HTTP 接口 |
| `client.js` | 浏览器半边。纯展示，不计算任何游戏状态 |
| `tools/` | 测试套件与发布脚本 |
| `dist/` | 发布产物，更新功能从这里下载 |
